2026-08-28 신설 · GPU 지출: 이 기록 자체는 0 · 인용하는 측정은 ≈0.9 GPU-hr

## 0. `deprecated/`와 무엇이 다른가
기존 `deprecated/`는 **현재 결론과 충돌해 격리된** 이력이다(2026-07-24 통합).
`deprecated_v2/`는 다르다 — 여기 모이는 수치는 **자기 스코프 안에서 여전히 참**이고,
달라진 것은 **그 스코프가 프로젝트의 새 실험 계열 밖으로 나갔다**는 사실이다.

⇒ **철회가 아니라 스코프 명시.** 인용 금지도 아니다. *"스코프를 함께 적지 않으면 인용 금지"*다.

★**정본 파일(`PROJECT_STATUS.md`·`CONSENSUS.md`)은 이 문서가 편집하지 않았다.**
정본 반영은 doc-steward 소관이며, 이 문서는 **비준 대상 초안**이다.

## 1. 왜 지금 생겼나 — 백엔드가 축이 됐다
TC1이 긴 프롬프트로 이동하면서 모델 계열이 Zamba2 → Nemotron-H로 바뀌었고,
그 과정에서 **엔진이 강제하는 제약**이 드러났다(전부 이 세션 실측):

| 조합 | 결과 | 근거 |
|---|---|---|
| Nemotron-H 계열 + `triton` | ❌ **부팅 거부** | `server_args.py:1959` 하드 assert — *"first layer might not be an attention layer"* |
| Zamba2 + `flashinfer` | ❌ **스케줄러 사망** | `RuntimeError: Triton Error [CUDA]: an illegal memory access` · **2/2 재현**(job 896776 태스크 1·3) |
| Zamba2 + `triton` | ✅ 정상 | activity 117줄 · `ZBPT2` 12줄 |
| Nemotron-Nano-9B + `flashinfer` | ✅ 정상 | job 896767 — 64요청 완주 · cudagraph 캡처 · 컨트롤러 이동 2회 |

⇒ ★★**두 모델 계열의 동작 가능 백엔드가 서로소다.**
⇒ ★★★**백엔드 효과와 모델 효과는 이 기판에서 분리 불가능하다.** *"모델 고정, 백엔드만 변경"* 셀을
어느 쪽으로도 만들 수 없다. 이것은 설계 실패가 아니라 **엔진이 강제하는 교락**이며,
rev2 감사 **B11**(*"cross-arm claims involving Hs8 must carry that caveat"*)이 그 축소판이었다.

## 2. 스코프가 드러난 수치 목록 (triton × Zamba2 한정)
아래는 **여전히 참**이되, **`--attention-backend triton` + Zamba2 계열**이라는 스코프를 벗어나
인용할 수 없다. 특히 **Nemotron-H 계열 arm으로 이전 금지.**

| 수치 | 정본 위치 | 스코프 |
|---|---|---|
| `Diff A`: attn ~ L^1.916±0.021 · mamba ~ L^0.954±0.008 (R²≥0.9996) | CONSENSUS §1-3 · research_arc S3 | triton · Zamba2-2.7B · no-cudagraph |
| `Diff A` 교차점 **≈3k tok** · 진폭 21× | 동 | 동 |
| `Diff B` steady L2000 = 1.0081 [1.0078, 1.0084] · L256 밴드 [1.24,1.34] | 동 | 동 |
| `R_policy ≈ 1 + w_attn·(DiffB−1)`, w_attn=9.6% | 동 | 동 |
| C2 국소 탄력도 16→24 = 0.77–0.88 · 44→92 = 0.09–0.35 | C2 인용정지 (a) 동반 | triton(3 arm) + flashinfer(Hs8) **혼합** — B11 |
| decode Diff B ≈ 4.0× (mamba SM-free) | research_arc S3 후속 | triton · Zamba2 |

★**파생 영향**: **R2′**(강등 길이 = `n_attn·c_attn(L) + n_mamba·c_mamba(L)`)는 이 계수들 위에 서 있다.
⇒ **Nemotron-H arm에서 R2′를 쓰려면 계수를 그 arm에서 다시 재야 한다.**

## 3. 이 세션의 재측정 — triton은 재현, flashinfer는 **측정 불가**
job **896776**(array 0–3, 같은 트리·같은 배치에서 짝으로 측정, 게이트 #41 드리프트 회피 목적):

| `full@L2000@B4` | 8 | 1778 | 3 | 4.5287 | 2.9080 | **1.557** |

★**`b_per_*`(BLOCK 필드, 매 emit 리셋 = steady)를 쓴다.** 같은 줄의 `per-attn`/`per-mamba`는
정본이 결함으로 등재한 **legacy 러닝평균**이다(누산기 미리셋 + cold start 포함).
**이 세션이 처음에 그 필드를 읽었다가 정정했다** — 다음 세션도 같은 실수를 할 자리다.

**읽기**: L 2000→8000에서 Diff A가 **≈1.5 → ≈3.4**로 열린다(방향은 정본과 일치).
⚠️**정본 수치와 직접 비교 금지** — 2026-07 빌드·다른 격자·다른 n이고, 이 표는 **백엔드 짝 비교용**으로
설계됐는데 그 짝의 한쪽(flashinfer)이 **측정 자체에 실패**했다.
⇒ **`Diff A`의 백엔드 의존성은 미측정이며, 이 기판에서는 측정할 수 없다**(§1).

## 4. 부수 발견 — 하네스·계측
- ★`results/prefill_knee/knee2d.sbatch:105`가 `grep "ZBPT mode=..."`를 찾는데 계측은 **`ZBPT2`**를 낸다.
  코드 주석이 **의도된 fail-loud**임을 밝히고 있다(*"pre-2026-08-04 parser가 조용히 다른 양을 읽지 말고
  실패하도록"*). ⇒ **`knee2d` 계열을 그대로 돌리면 `RESULT` 줄이 전부 빈 채 `boot_ok=1`로 "성공"처럼
  끝난다.** 이 세션은 서버 로그에서 직접 파싱해 우회했다. **하네스가 스테일이다.**
- `boot_ok=1`은 **health 엔드포인트 통과일 뿐** 요청 처리 성공이 아니다(flashinfer arm이 그 상태로
  죽었다). 스모크·하네스의 `boot_ok`를 성공 신호로 읽지 말 것.
