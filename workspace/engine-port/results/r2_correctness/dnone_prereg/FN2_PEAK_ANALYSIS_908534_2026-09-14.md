## 8. 통계 게이트 적용 가능성
| 게이트 | 적용 | 판정 |
|---|---|---|
| **n ≥ 4** | 적용·**불충족** | guard 축 DN boot **n=1**(사전등록 §6-4가 포트 예산 구조 한계로 공시) ⇒ **정책 결론용 검정력 없음**. 성격은 *underpowered*보다 **replication-limited**(comparator 산포 0–4.29 MiB ≪ 효과 7 MiB–7.55 GiB ⇒ noise-limited 아님) |
| **paired bootstrap CI** | **적용 불가** | 짝의 단위가 boot인데 DN 표본 1개. **epoch 35개를 짝으로 부트스트랩하는 것은 금지** — epoch은 같은 boot 안의 직렬 상관 구간이고(Δ가 경계를 넘어 샌다, §5) 같은 궤적을 공유한다. ⇒ **CI·p-value·sign-test 산출하지 않았고 산출해서도 안 된다** |
| 3% 헤드라인 | 해당 없음 | goodput/시간 지표 아님. 대체 기준 = "관측 boot 산포 천장 4,494,336 B 초과"(35/35 초과) |
| metric cliff | 다른 형태로 존재 | **절단 편향**·**창 길이 비대칭** 둘 다 부호 방향 **보수적** |
| duration 합산 버그 | 해당 없음 | 분모(시간) 없음, round append 아님(`dropped_events=0`) |
| 성능 주장 | **금지** | `RR-1`(짝지은 on/off 측정 부재) |

**다음에 필요한 것**: guard 축에 구간을 붙이려면 `guard=none` boot **최소 1개 추가(≥2)**,
guard-축 게이트 #232 양성 대조에는 **2개**, n≥4 관례에는 **3개 추가**. 그리고 DN이
`#new-token ≥ 10036` rung에 도달하지 못하는 한 **10125에서의 Δ는 영구히 반사실**이다.
