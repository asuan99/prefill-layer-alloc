## 0. 한 줄

**"부족분이 커널 안인가 밖인가"는 간극이 *커질 때만* 판별된다. 간극이 *일정할 때*(= 이 기판에서
물리적으로 가장 그럴듯한 경우)는 반사실 선택이 답을 정하며, 그것은 데이터로 풀리지 않는다.**
⇒ rev6는 **반사실이 필요 없는 서술적 분해를 1차**로 두고, 반사실 쌍은 **2차 민감도 표시**로
강등하며, `COUNTERFACTUAL_SENSITIVE`를 **실패가 아니라 사전등록된 결과**로 선언한다.

## 1. ★작동특성 — 사전 계산 결과 (감사 C4에 대한 답)

`rev6_power.py`(BCa 부트스트랩, 부팅 n=4, 반복 400, 부팅 CV 1·2.5·5% 스윕, seed 고정).

| 부과한 진실 (K44,G44 → K92,G92) | `s`(비대칭) | `s`(대칭) | 판정 결과(cv 1–5%) |
|---|---|---|---|

| **간극이 실제로 커짐** (60,40 → 32,60) | 0.858 | 0.925 | ★**`GAP` P=1.00** (전 cv) |
| **간극 불변·커널 잘 줄어듦** (50,50 → 30,50) = 감사 CE-1 | 0.000 | 0.811 | ★**`SENSITIVE` P≈1.00** |
| **혼합** (70,30 → 45,40) | 0.465 | 0.690 | `SENSITIVE` P≈1.00 |

★**세 가지가 이 표에서 확정된다**:
1. **양 극단은 판별된다** — 커널이 안 줄어들면 `KERNEL`, 간극이 **커지면** `GAP`. 둘 다 P=1.00.
2. ★**간극이 *일정*하면 두 반사실이 반대 판정을 낸다**(0.000 vs 0.811). 이건 잡음이 아니라
   **정의의 문제**다 — 일정한 간극을 "부족분"으로 셀지가 반사실 선택이다. rev5 감사 C1이
   *"`GAP_DOMINATED` 도달 불가"* 라 한 것의 정확한 형태: **`GAP`은 도달 가능하되 간극이

3. ★**부팅 CV(1%→5%)가 판정을 거의 바꾸지 않는다** ⇒ **구속 요인은 잡음이 아니라 구조**다.

⇒ **설계 결론**: 반사실 쌍을 1차 판정으로 쓰면 **가장 그럴듯한 세계에서 항상 기권**한다.
그래서 rev6는 **1차를 서술적 분해로 바꾼다**(§3).

## 2. 결정량 — 시계와 멤버십 (감사 C2·C3 해소)

```
K_set(k)  := 스텝 k 경계 안에서 **집행이 완결된**(start ∧ end 모두 포함) decode green-ctx
             스트림 커널.  ★멤버십은 launch(호스트 사건)가 아니라 **집행 포함**이다(C2).
             경계를 걸친 커널이 1개라도 있으면 그 스텝을 폐기한다(교집합 계상 금지).
             NVTX↔커널 결합은 **launch API correlation-id 경로**로만 한다(집행 타임스탬프가
             NVTX 범위에 드는지로 붙이지 않는다).
Σkernel_dur(k) := | ⋃_{i∈K_set(k)} [start_i, end_i] |          # 합집합, T에서 역산 금지
T_span(k) := (마지막 커널 end) − (첫 커널 start)
G_intra(k) := T_span(k) − Σkernel_dur(k)        # ★1차 판정 입력 (커널 사이 device 유휴)
G_inter(k) := (다음 스텝 첫 커널 start) − (이 스텝 마지막 커널 end)   # 호스트/launch 지연
T_step(k) := T_span(k) + G_inter(k)
```
★**C3 해소**: rev5는 `G_dev` 하나에 **스텝 내 유휴와 스텝 간 호스트 지연을 섞어** 놓고
*"호스트는 후보가 아니다"* 라고 적었다. rev6는 **정의로 분리**한다. `G_inter`가 크면 그건
**후보 집합 밖의 사실**이고 아래 `HOST_DOMINATED`로 **명명해 보고**한다(숨기지 않는다).

**항등식 가드**(명명 assert, 합성 fixture + 변이 테스트, 교훈 #53):
`A1_UNION_NOT_SUM`(겹침 포함 fixture) · **`A2_INTERVALS_ONLY`** ★감사 v1 해소 —
`Σkernel_dur` 계산 함수는 **구간 리스트 `List[(start,end)]` 하나만** 받는다(시그니처 축소로
역산이 **구조적으로 불가능**해진다. 이름 수준 AST 검사보다 강하고, 국소 재계산 변이본도
통과할 수 없다) · `A3_NO_CLAMP` · `E1_NO_PREFILL_KERNEL` · ★`A5_CONTAINMENT`(경계 걸침 커널이
있는 스텝은 폐기되는가).

## 3. 판정 — 1차는 서술, 2차는 민감도

### 3.1 ★1차(반사실 없음) — 이것이 캠페인의 산출물이다

D ∈ {16,44,92} 각각에서 **CI와 함께** 보고한다:

| 양 | 정의 | 성격 |
|---|---|---|
| `gap_frac_intra(D)` | `G_intra / T_span` | ★**핵심 서술량** — "스텝 시간의 몇 %가 커널 밖 device 유휴인가" |
| `frac_inter(D)` | `G_inter / T_step` | 호스트/launch 몫(후보 집합 **밖**) |
| `K(D)`, `T_step(D)` | 절대 시간 | 규모 |
| `ε_T(D₁→D₂)` | `−ln(T_step 비) / ln(D 비)` | 평탄화의 통화 |

★**이 넷은 반사실을 필요로 하지 않으며 어떤 진실 하에서도 산출된다.** 예컨대 *"D=92에서
스텝의 62.5%가 커널 밖 device 유휴다"* 는 **정의 논쟁 없이 참/거짓이 갈리는 문장**이고,
정본이 지금 갖고 있지 않은 사실이다.

### 3.2 2차(반사실 쌍) — 사전등록된 기권을 포함

```
CF-A(비대칭): K_ideal = K(44)·44/92,  G_ideal = G_intra(44)
CF-B(대칭)  : K_ideal = K(44)·44/92,  G_ideal = G_intra(44)·44/92
s_X := S_G / (S_K + S_G),  S_K := K(92) − K_ideal,  S_G := G_intra(92) − G_ideal
```
| 판정 | 조건 |
|---|---|
| `KERNEL_DOMINATED` | **두 반사실 모두** CI 전체 < 0.5 |
| `GAP_DOMINATED` | **두 반사실 모두** CI 전체 > 0.5 |
| `MULTI_CAUSE` | 두 반사실 모두 CI ⊂ [0.15,0.85] ∧ 0.5 포함 |
| ★`COUNTERFACTUAL_SENSITIVE` | 두 반사실이 **다른 판정** — ★**결과다. 실패가 아니다.** §1 표가 이 결과의 확률을 사전에 못박았다(간극 불변 세계에서 P≈1.00) |
| `HOST_DOMINATED (후보 집합 밖)` | `frac_inter(92)`가 `gap_frac_intra(92)`를 넘음 — 후보 (ii)(iv)로 귀속하지 않는다 |
| `UNDETERMINED` | 선행 게이트 실패·셀 폐기·`S ≤ 0` |

★**대수 명시(게이트 #40 집행)**: `S_K ≥ 0`(커널이 초선형 가속되지 않는 한)이므로
**CF-A에서 `s>0.5`의 필요조건은 `G_intra(92) > G_intra(44)`** 다. 즉 CF-A는 *"간극이 커졌는가"*
를 묻고 CF-B는 *"간극이 SM에 비례해 줄지 않았는가"* 를 묻는다 — **다른 질문**이고, 그래서
간극 불변 세계에서 갈린다. 이 문장을 문서에 박아 둔다.

**회귀 fixture(하네스 필수)**: 감사 **CE-1**(50,50→30,50)과 **rev4 반례**(95,5→80,20)를
넣고 각각 `COUNTERFACTUAL_SENSITIVE` / `KERNEL_DOMINATED`가 나오는지 검사한다.

### 3.3 선행 게이트 — 정본 수치를 인용하지 않는다 (감사 C5 해소)

rev5는 정본 국소 ε 밴드를 인용해 문턱 여유를 주장했다가 **삼중 무효**(구간 오인용 · 인용정지
(a) 대상 · 같은 문서가 "다른 양"이라 선언) 판정을 받았다. rev6는 **절대 문턱을 쓰지 않고
관계식만** 쓴다:

> **레버 존재 게이트**: `ε_T(16→44)`의 CI **하한**이 `ε_T(44→92)`의 CI **상한**보다 크다.

이 하나로 "저-SM에선 레버가 듣고 고-SM에선 안 든다"(= 평탄화의 정의)가 **이 캠페인 자신의
데이터로** 확립되거나 실패한다. **정본 숫자 0개, 자유 문턱 0개.** 실패하면
`UNDETERMINED (PHENOMENON ABSENT IN CELL A)` — 가설 반증이 아니라 재범위화다(게이트 #21).

### 3.4 불확실성

부팅×창 2단 **BCa** 부트스트랩(seed 고정, B=10,000). ★**percentile 구간은 쓰지 않는다** —
정본이 본문 사용을 금지했다(과소피복 M8 1.36×·Ha8 1.55×). 비 `s`는 분모가 0을 가로지를 수
있으므로 **재표본 내 `S ≤ 0` 발생률을 보고**하고, 5%를 넘으면 2차 판정을 `UNDETERMINED`로 둔다.

### 3.5 자유 모수 전수 (4개)

`0.5`(`s` 문턱 — **유도됨**: 부족분의 과반) · `[0.15,0.85]`(`MULTI_CAUSE` 밴드) ·
`10`(셀당 최소 적격 창) · `20`(창당 최소 decode step). ★rev5가 "전수 5개"라 적고 6개를
나열했던 오류를 정정했고, **`CONC`·`L`·seed·배치 등가 조건을 §5에 값으로 고정**해 목록 밖으로
뺐다(감사 C6·v8).

## 6. `U_infl` — 전제를 바꾼다 (감사 C7·B8 해소)

`K = T − G`이므로 `U_infl`은 `s`에서 **대부분 상쇄되고 실제로 남는 것은 `U(92) − U(44)`** 다.
⇒ 전제를 *"`U_infl`을 측정한다"* 가 아니라 ★**"`|U(92) − U(44)| ≪ S` 임을 확인한다"** 로
재정의한다. 측정은 **D=44·92 두 점에서만** `--cuda-graph-trace=node` vs `=graph` 부팅쌍
(**4 부팅**, 예산에 계상). 보정은 분자·분모 **동시**(`(G−U)/(T−U)`), CI 전파.
`G_corr ≤ 0`은 폐기가 아니라 **`GAP_BELOW_RESOLUTION`**(명명된 결과)이며, ★rev5가 이를
*"`KERNEL` 방향 증거"* 라 읽은 것은 **방향성 과잉 독해**였으므로 삭제한다 — 정보 있는 음성까지만.
