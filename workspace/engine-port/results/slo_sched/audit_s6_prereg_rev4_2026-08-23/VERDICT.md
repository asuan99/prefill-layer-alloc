### F2 — ★★★ **E4 잔여: `set -u`는 고쳤으나 채택 경로를 부쉈다. OFF 부팅 채택률이 0이다** (실증)

**문제.** §4.2 표(line 313)는 `:701`의 OFF 처리를 *"`TELEM_RC` 대신 **`N/A(telemetry=OFF, by design)`**"*
로 등록한다. 3회차 E4 수리 문구는 **다른 것**을 요구했다: *"`:701`의 H2' assert와 `:752`의

뒤 `telem_na="by_design"`을 기록한다"*. rev4는 **명시 대입을 삭제하고 라벨만 남겼다.**

**실증**(실 bash, `/usr/bin/bash --noprofile --norc`):

```
TELEM_RC=""                              -> [: : integer expression expected            -> ARTIFACT_OK=0
TELEM_RC="N/A(telemetry=OFF, by design)" -> [: N/A(...): integer expression expected     -> ARTIFACT_OK=0
TELEM_RC=0                               -> (정상)                                       -> ARTIFACT_OK=1
```

`g16_grid.sbatch:615`가 `TELEM_RC=""`로 초기화하고 `:802`가 `[ "$TELEM_RC" -eq 0 ] || ARTIFACT_OK=0`,
`:810-817`이 `ARTIFACT_OK != 1` → `BOOTS_FAILED++` + `mark_failed_artifacts` + `write_sidecar "$RUNID"
artifact_invalid`다. ⇒ **§4.3-1의 `status == "completed"` 가 OFF 다리 전 부팅에서 불만족**된다.
`n=12` 고정 설계에서 OFF 12개가 전부 거부되면 완주 쌍 수 `m=0` ⇒ §3의 부분 완주 규칙에 따라
**`UNDETERMINED (CAMPAIGN INCOMPLETE)`**, 3.146 GPU-hr 전액 소실.

**★그리고 §4.2 표는 또 "전수"가 아니다(다섯 번째).** 표는 `$PDMUX_TELEMETRY_PATH` **역참조 4곳만**
열거하는데, OFF 다리가 실제로 건드리는 것은 그 4곳의 **하류 rc 소비처**다:
`TELEM_RC` → `:381`(사이드카 export) · `:802`(ARTIFACT_OK) · `:807`(ARM_SUMMARY) · `:812`(ARTIFACT_INVALID) ·
`:837`(SMOKE1) · `:955`(SMOKE9 요약) / `CTRLSUMMARY_RC` → `:772` · `:808` · `:958`.
**표에 한 줄도 없다.**

**부수 정정 3건**(전부 실측):
* line 295의 `unset + set -u -> **rc=127**` 는 **틀렸다**. 실측 **rc=1**(3회차 감사값과 일치).
  127은 "command not found"다 — 이 재현이 무엇을 쟀는지 문서로는 알 수 없다.
* `: > ""` 는 실측 `": No such file or directory"`(그 명령 rc=1)이나 **`set -e`가 없어 비치명**이고
  스크립트는 계속 진행한다. ⇒ 표의 *"가드로 건너뛴다"* 는 **필수가 아니라 위생**이다(정직하게 적을 것).

**수리 문구.** §4.2 표를 **rc 소비처까지** 확장하고 다음을 등록한다:
★*"OFF 다리는 `:701`·`:752`·`:875`의 호출을 **건너뛰고** `TELEM_RC=0`·`CTRLSUMMARY_RC=0`을 **명시
