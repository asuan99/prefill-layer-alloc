### 2-3. ★§1-20 대조는 극도로 절벽 위다 (rev2 신설)

TTFT 임계를 **3000 ms ±10%**(2700–3300, 15 ms 스텝 41점)로 훑으면 legacy 술어 이득이:

| | 값 |
|---|---|
| 운영점(3000 ms) | **+16.23%** |
| **최소** | **+0.00%** (2715 / 2745 / 2760 / 2775 / 2790 ms) |
| **최대** | **+19.75%** (3270 ms; 3300 ms에서 +19.42%) |
| 단조성 | **비단조** |
| 구조(Tdon=d16 / Idon=d24 / SM=116) | 41점 중 **39점 불변**, **2760·2775 ms에서 Tdon이 d24로 붕괴하고 SM=108** |
