## 1. 결론 (한 줄)
**둘 다 맞되 정의가 다른 경우가 아니다.** 2.74–3.26 / 2.97–3.12 / 1405–1475 s는 `audit_r1_sus.py:16`의 **단위 오류**
(`sent_s + completion_s`, 이미 절대 시각인 `completion_s`에 `sent_s`를 한 번 더 더함)에서 나온 값이다. 물리적 의미가 있는 값은
하네스 감사 쪽(마지막 완료 820–865 s, 완료 수 ÷ 마지막 완료 5.06–5.34 req/s)이다. "지속 용량 ≈ 3.0"은 근거가 없다.

## 2. `completion_s`의 의미 (판정 근거)
- 코드: `benchmarks/pdmux_eval/trace_loadgen.py:116-117` — `"sent_s": sent - benchmark_started`, `"completion_s": finished - benchmark_started`.
  즉 `completion_s`는 **run 시작 기준 절대 완료 시각**이고 지연(latency)이 아니다.
- 데이터: 4 run 전 4,377×4 요청에서 `completion_s == sent_s + ttft_ms/1000 + Σtoken_itl_ms/1000` (최대 잔차 0.000 s),
  `completion_s < sent_s + TTFT`인 요청 0개.
- 물리적 상한: run 메타 `duration_s` = 838.5 / 866.2 / 821.4 / 850.0 s(D44 s201 / D44 s202 / D64 s201 / D64 s202),
  D44 s201 벽시계(`wall_end − wall_start`) 841.3 s. 정의 B의 "마지막 완료 1404.6–1474.8 s"는 run 자체보다 길어 **불가능**하다.
- 같은 필드를 다른 도구는 올바르게 쓴다: `stock_baseline/stock_metrics.py:127` `e2e = completion_s − sent_s`, `sb_runner.py:374` `completion_s // window_s`.

## 6. 해석 범위 (회의적 한정)
- 5.06–5.34(정의 A)는 **7.29 req/s 과부하·큐 무한 증가 상태의 포화 완료 처리율**이다(n=4 run, 2 D × 2 seed, 한 Job·한 GPU).
  이 구간 attainment는 첫 60 s 창 이후 0(TTFT p50 217–240 s)이므로 게이트 4 차단형 — 이 값은 goodput이 아니고, "SLO를 지키는
  지속 가능 rate"도 아니다. SLO 기준 지속 용량은 이 데이터로 정해지지 않는다(그 rate는 5.1보다 작거나 같다는 것만 말할 수 있고,
  하한은 없음).
- 감사 r1 (3)의 파생 서술도 같이 무너진다: "HE0 LO 2.74는 지속 완료율의 0.88–0.92(경계 근처)"는 정의 A에서 0.51–0.54다.
  "λ*_W1 버스트 7.29 vs 지속 3.0 = 2.4배"(`reports/audit/2026-11-01_design_defects/REPORT.md` S6)는 정의 A로 7.29/5.06–5.34 ≈ 1.4배.
- 영향 받는 인용(수정은 하지 않음, promote/doc-steward 몫): `policy_cap2/RESULT_cap2_sustain_2026-10-29.md:34·51·55`,
  `policy_cap2/AUDIT_cap2_sustain_result_r1_2026-10-29.md:10·12·15·20·30`, `tracks/main.md:14`("완료율 ≈3.0"),
  `reports/audit/2026-11-01_design_defects/REPORT.md:16`(S6), `stock_baseline/PREREG_STOCK_BASE_rev1_DRAFT_2026-11-02.md:84`(§7 "기준 용량 3.0 req/s 가정" — 시간 모형 입력이므로 재계산 필요).
- "λ*_W1 7.29는 600 s 비지속"이라는 **정성 서술은 유지된다**: 도착 7.29 > 완료 5.06–5.34, 큐가 해소되지 않고 attainment 0. 바뀌는 것은 지속 처리율 크기(3.0 → 약 5.2)와 그로부터 나온 비율들이다.
