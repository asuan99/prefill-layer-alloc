# AF-1 채점 제외 boot (삭제하지 않고 격리 — 게이트 #88)

여기 있는 round는 **AF-1 추정량에 들어가지 않는다.** 삭제는 등록이 아니므로 지우지 않고
격리한다. `af1_analyze.py --glob 'af1_*_*'` 는 최상위만 훑으므로 이 디렉터리는 잡히지 않는다
(`af1_discarded` 에는 밑줄이 하나뿐이라 패턴 불일치).

| round | 성격 | 제외 사유 |
|---|---|---|
| `af1_904819_0` | 배관 스모크 1 | 셀 단위로 들여다봄 — 워밍업 오염 발견 (addenda C) |
| `af1_904845_0` | 배관 스모크 2 | 셀 단위로 들여다봄 — 워밍업 수리 검증·파티션 무발화 확정 (addenda E) |
| `af1_904851_0` | 동거성 측정 | 셀 단위로 들여다봄 — 호스트 동거 효과 정량화 (addenda F) |
| `af1_904851_2` | 중도 취소 | `scancel` 로 부팅 중 중단, 산출물 불완전 |
| `af1_904851_3` | 중도 취소 | 위와 같음 |

사후 관찰된 boot를 추정량에 넣는 것은 금지된다(게이트 #3·#8). 이 파일들은 **계측·검증
증거**로만 인용한다 — 성능 판정의 근거로 재사용 금지.

**살아남은 boot**: `af1_904851_1` (seed 23) 는 로드만 되고 **어떤 값도 출력되지 않았다**
(addenda F 의 비교표는 `904851_0` 만 인쇄한다) ⇒ 미관찰, 채점 대상으로 유지.
