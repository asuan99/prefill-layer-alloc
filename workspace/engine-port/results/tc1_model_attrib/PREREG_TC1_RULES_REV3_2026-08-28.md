## 0. rev2가 자기 검사에 걸렸다 — 그리고 rev3는 통과한다

rev2는 감사 이후 **설계층 도달가능성 검사**(`../REACHABILITY_FINDING_2026-08-28.md`)에서

(`reach_spec_rev3_A.json` / `reach_verdict_rev3_A.json`)

## 2. 질문 (재정식화)

> **동적 arm의 상대효과가 두 모델에서 다른가?** `θ_T − θ_H`, `DELTA_INT = 0.06`.
> 유의 ∧ 두 `θ` CI가 **반대 부호** ⇒ `FLIP_MODEL_ATTRIBUTED` /
> 유의 ∧ 같은 부호 ⇒ `MAGNITUDE_DIFFERS_NO_FLIP` / TOST 통과 ⇒ `NO_INTERACTION`.

★`MAGNITUDE_DIFFERS_NO_FLIP`은 **신설 라벨**이고 실제로 일어날 수 있는 결과다 —
*"두 모델에서 동적의 손해 크기가 다르지만 둘 다 진다"*. rev2에는 이 라벨이 없어
그 세계가 `BOTHLOSE`로 접혀 있었다.

## 3. 대조
- **음성 = 모델 라벨 치환**(2×2 안에서), 귀무 발화율 전수 산출. **비퇴화성이 통과 조건**(§1 F7).
- **양성 = T arm 동적 셀에 `+2·DELTA_INT` 주입**, **원시 rep 수준**에서. 반드시 발화.
- **변이 = 양성·음성을 맞바꾼 판본에서 반드시 실패.**
- ★`0` 주입은 **쓰지 않는다**(F7).

## 4. 닫지 못하는 것
1. **두 체크포인트 비교다** — 상호작용도 이걸 고치지 못한다. 파라미터·층수·tokenizer 차이는 남는다.
   rev1의 "부호는 재척도 불변" 방어는 **철회 상태 그대로**다.
2. flip이 발화해도 **"왜"에는 답하지 않는다**(층 조성 / admission-mamba pool 결합, 최소 둘).
3. **`edge_lo` 구조적 미해소**(d08 자산 부재).
4. `MAGNITUDE_DIFFERS_NO_FLIP`은 **모델 귀속을 확립하지 않는다** — 크기 차이는 부하·용량 차이로도 난다.
5. ★**rev3는 F5–F7의 *설계* 수리이지 실증이 아니다.** 감사가 *"이 처방만으로 캠페인은 못 산다"*고
   적었고, 그 판정은 재감사가 갱신하기 전까지 유효하다.
