### 1.1 ★`W` 선택의 도출 (자유 표면 후보 #1 — 아래 §5에 등재)

`W`는 두 제약의 교집합에서 골랐고, **양쪽 다 프로브 C 실측 상수만 쓴다**:
- **하한**: knee 아래에서는 arm이 구별되지 않는다(W1) ⇒ 최소 한 arm이 `ρ ≥ 0.6`.
- **상한**: TTFT가 metric cliff로 가면 CDF가 붕괴한다(게이트 #6) ⇒ 모든 arm에서
  `bench duration`이 도착 창에 지배되거나 drain 초과가 2배 이내.

`out=96 → W=0.60`: `ρ` = 0.64 / 0.89 / **3.21**(d92만 과부하 — 불가피, §5-#5).
`out=384 → W=0.25`: `ρ` = 0.29 / 0.40 / **1.49**.
⚠️**d92는 어느 `W`에서도 과부하다**(μ_p=0.187/0.168). 이건 선택이 아니라 기판의 성질이다.

### 1.2 ★관측 창을 맞춘다 — `N`이 아니라 (rev2 死因 X5-c 수리)

발생하는데 P6엔 없다). ⇒ **`N`을 맞추는 대신 창을 맞춘다**:

`N_cell = round(180 s × min(W, μ_p(D, out)))` — `μ_p`는 프로브 C 실측(§4-A).

## 2. ★등록 규칙 — 전부 **결정 규칙 위에서** 정의 (게이트 후보 #104)

### 2.1 규칙 안에서 쓰는 양의 정의 (rev2 차단 B4 수리 — "미해결"이 아니라 규칙 절에 둔다)

```
p95(ITL_i)      := np.percentile(itls[i], 95)          # 요청 i 내부, 선형보간
itl95_cell(D,R) := median_i p95(ITL_i)                 # 셀 대표값
F_D,R(T)        := (1/N)·Σ_i 1[TTFT_i ≤ T]             # TTFT 경험 CDF
span_hat        := duration − (ttfts[-1] + Σ itls[-1]) # 도착 스팬 (rev2 §R5, 오차 0.077%)
L_decode_exact  := Σ_i Σ(itls_i) / duration            # Little 적분형
```

`itl95_cell`·`F`는 **부팅 단위로 계산한 뒤 부팅 간 평균**한다(격자·요청 풀링 금지 —
rev2 반증 실패 8).
