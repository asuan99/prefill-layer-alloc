## 0. 질문과 estimand (먼저 못박는다)

**질문**: `CONSENSUS §5-6`이 stake #1로 명시한 *"최적 static split 위치가 워크로드 모양(`R`)에
따라 움직이는가"*.

**estimand = ITT(intention-to-treat), 정책 층.** 노출은 **설정값** `PDMUX_R2_FIXED_DSM = D`이며,
실현 파티션·듀티사이클은 **병기 공변량**이지 조건화 대상이 **아니다**. 근거는
`DIRECTION_2026-09-08.md`의 (ㄴ) 채택: 이 트랙을 12연속 죽인 자리는 **per-protocol 조건화**이고,
비순응(realized ≠ target)의 원인이 처치 자신이므로 **collider**다.

★**ITT가 되살리는 것과 되살리지 않는 것**:
- **되살린다**: *"이 설정에서 이 워크로드에 이 goodput이 나온다"* = 정책 진술.
- **되살리지 않는다**: *"decode SM이 원인이다"* = 기전 진술(Gate 2, "PD 분리 자체" 귀속).
  이 캠페인은 Gate 2를 **열지 않는다.**

★**따라서 §7의 arm 간 decode 인구 격차(14.9×)는 이 estimand에서 교락이 아니라 처치 효과의
일부다.** 그것이 교락이 되는 것은 기전 estimand에서뿐이고, 이 문서는 기전을 주장하지 않는다.
**이 구분을 흐리는 서술은 등재 금지.**

## 2. ★SLO — 도출 출처를 명시하고 실행 전 동결

**Primary = SLO goodput**(방법론 게이트 #4): 요청 `i`가 **`TTFT_i ≤ T_slo` AND
`p95(ITL_i) ≤ I_slo`**를 동시에 만족하면 good. `G(cell) = #good / #completed`.

| SLO | 값 | 도출 |
|---|---|---|
| `T_slo` | **9.1 s** = `10 × floor_ref(8192)` | 장문 배치/RAG의 조작적 규범 = 고유 prefill 비용의 작은 배수. **정본 3 s는 이 ctx에서 물리적으로 불가**(무경합 바닥 0.91 s, knee 부하 TTFT p50 7.6–63 s ⇒ 전 arm goodput 0 = 게이트 #6 절벽). |
| `I_slo` | **60 ms/token** (≈16.7 tok/s) | 대화형 하한. **절벽 회피가 값을 정했다 — §2.1.** |

★**이 두 값은 프로브 C(job 905835)의 관측에서 절벽 위치를 피해 골랐다.** 프로브 C와 이
캠페인은 **별개의 런**이므로 calibration → confirmatory 관계이고 순환이 아니다. 다만 **출처를
숨기지 않는다**: 아래 §2.1의 계산이 값 선택의 전부이며, 실행 후 **어떤 재조정도 하지 않는다**.

### 2.1 ★절벽 사전 진단 (게이트 #6) — 왜 50 ms가 아니라 60 ms인가

ITL 분포는 **매우 좁다**(프로브 C, d16 out=96: p50 45.2 ms · p95 **47.0** ms). SLO를 50 ms로 두면
`p95(ITL)`가 문턱에서 **6%** 거리 ⇒ 미세한 이동이 goodput을 0↔100%로 뒤집는 **절벽**이다.
60 ms는 d16 out=96(47.0 ms)에서 **1.28×**, d16 out=384(87.1 ms)에서 **1.45×** 떨어져 있어
양쪽 다 절벽이 아니다.

반대로 **TTFT는 절벽이 아니다** — 분포가 넓다(out=384 d16: p50 7.61 s · p95 14.73 s). `T_slo`
근처에서 goodput-vs-SLO 곡선이 매끄럽고, 통과율이 0/100이 아닌 중간대에 앉는다(= 판별력 최대).

### 2.2 등록된 예상 통과 구조 (프로브 C 동작점 기준, **예측이지 판정 아님**)

| | ITL leg | TTFT leg |
|---|---|---|
| d16 | out=96 통과 / **out=384 탈락**(87 ms) | 양쪽 통과 쪽 |
| d44 | 양쪽 통과(23–26 ms) | 경계 |
| d92 | 양쪽 통과(16 ms) | **양쪽 탈락**(TTFT p50 31.8–43.6 s) |

⇒ **두 leg가 서로 반대 방향으로 arm을 가른다.** 어느 leg도 자명하게 비구속이 아니다.

## 3. ★등록 규칙 — 전부 **대수 전개해** 항등식 여부를 확인했다

> 이 절은 `PREREG_CAPACITY`에서 **규칙 2개가 항등식이었던 실패**(R4 대수 항등식 · R1 아래 다리
> 시드 자동통과, `probes/c_905835/REPORT.md` §5)에 대한 직접적 대응이다. 방법론 게이트 #9.

| # | 이름 | 규칙 | 항등식 검사 |
|---|---|---|---|
| **S1** | `ARGMAX_MOVES` | `W` 고정 시, `R=0.42`의 `argmax_D G`와 `R=0.15`의 `argmax_D G`가 **다르고**, 각 `R`에서 1위와 2위의 paired bootstrap 95% CI가 **0을 포함하지 않는다** | `G`는 측정 지연을 **외부 고정 문턱**과 비교한 지시함수의 평균. 어떤 설계 상수로도 재진술되지 않는다. `argmax`는 3값 이산량으로 3가지 결과 전부 도달 가능. **항등식 아님** |
| **S2** | `D92_CAPACITY_DEAD` | 전 셀에서 `G(D=92) < 0.05` | `G ∈ [0,1]`, 문턱 0.05는 내부점. 프로브 C 기준 d92 TTFT p50가 `T_slo`의 3.5–4.8배라 **탈락이 예상되지만**, `W=0.35`에서는 통과할 여지가 있다(μ_p=0.187이라 ρ=1.87 — 여전히 과부하). **자기기각 아님·자동통과 아님** |
| **S3** | `LOAD_REALIZED` | 각 셀의 **실현 도착률**(§4-C)이 명목의 **[0.93, 1.07]** 안 | ★프로브 C에서 단일 시드가 명목을 15–21% 벗어났다. n=6 서로 다른 시드의 **평균**은 CLT로 ±(1/√6)·CV로 좁혀진다(지수 도착 CV=1, N≈130 ⇒ 셀당 s.e.≈`1/√(6·129)`≈3.6%) ⇒ [0.93,1.07]은 **도달 가능하고 자동 통과도 아니다** |
| **S4** | `DUTYCYCLE_REPORT` | split 시간가중 듀티사이클과 `L_decode_exact`를 **병기 보고** | ★**문턱 없음 — 게이트 아님.** ITT이므로 실현량으로 조건화하지 않는다(§0) |

### 3.1 ★`G`가 항등식이 아님을 명시적으로 전개

`G = (1/N)·Σ_i 1[TTFT_i ≤ 9.1] · 1[p95(ITL_i) ≤ 0.060]`.
우변에 `floor_ref`·`itl_solo`·`R`·`μ_p`·`s(D)` **어느 것도 들어가지 않는다**. `PREREG_CAPACITY`
R4가 죽은 이유는 예측량과 관측량이 **같은 측정치의 재배열**이었기 때문인데, 여기서는 문턱이
**측정과 무관한 외부 상수**다. ⇒ 구조적으로 그 실패가 불가능하다.

### 3.2 ★null은 주장하지 않는다 (승계)

`ARGMAX_MOVES`가 발화하지 않아도 **`ARGMAX_STABLE`을 주장하지 않는다** — 최적점이 안 움직였다는
등가성 주장은 반대 방향의 보수성(TOST 마진)을 별도 등록해야 하고, 이 캠페인은 그걸 등록하지
않는다. 발화 실패 시 결론은 **"움직임을 보이지 못했다"**뿐이다.

## 6. ★미해결 — 감사에 먼저 회부하는 항목 (숨기지 않는다)

1. **검정력 재계산 미완**: n=6의 0.868은 시드-도착 분산 미포함. 이 캠페인을 돌리기 전에
   프로브 C의 셀 내 분산으로 재계산해야 한다. **현 시점 n=6은 근거 없는 승계다.**
2. **arm 격자가 성기다**: `D ∈ {16,44,92}`인데 d92는 용량으로 죽을 것으로 예상(S2) ⇒
   실질 2-arm 비교다. 최적점이 "움직인다"를 검출할 해상도가 낮다. `homog5`에 division을
   더하면 새 boot-sanity가 필요하다.
3. **`W` 2수준이 충분한가**: arm별 μ_p가 5배 다르므로(0.187–0.933) 공통 rate는 arm마다
   전혀 다른 ρ다. ITT에서는 그것이 처치 효과의 일부지만, `W` 2점으로 `R×W` 상호작용을
   식별할 수 있는지는 미검토.
4. **`T_slo = 10×floor_ref`의 자의성**: 10은 라운드 넘버다. 외부 근거(응용 규범)가 아니라
   내부 편의다. `serving_slo_survey.md`는 장문 배치 규범을 담고 있지 않다.
5. **out=384의 knee 미측정**: 프로브 C의 out=384 셀 3개는 전부 arm-상대 1점이라
   `μ_p(D, out=384)`를 모른다. `W ∈ {0.35,0.60}`이 그 knee의 어느 쪽인지 미확인.
6. **`--max-prefill-tokens` 미지정 승계**(P1/P2/프로브 C와 동일, `PREREG_RATIO` §3.3과 상이).
