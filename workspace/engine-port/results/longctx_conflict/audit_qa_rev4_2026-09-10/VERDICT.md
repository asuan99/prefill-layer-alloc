## 9. 처방 (각각 자기 실현가능성 검사 포함 — 게이트 #113)

### R1 (필수·비용 0) — `min` 기반 스칼라를 산출에서 **완전히 제거**하고 쌍 행렬만 등록
`min`은 추정량마다 다른 기준 arm을 고르므로 **쌍 행렬의 함수가 아니다**(파생이 아니다).
**자기검사**: ✅비용 0·✅argmin 전환 소멸 · ⚠️**충분하지 않다** — 쌍 차 자체도 추정량 확산이 남는다(d44−d54: 1.5201 / 1.2854 / 0.4935 / 0.4409 = **3.4×**) ⇒ R2 필요.

### R2 (필수·비용 0) — 모드 가중 `u`를 1급 산출로 등록하고 **추정량별 mode-pinned 플래그**를 등록
`u := (ITL < c_valley)` 비율, `c_valley`는 **측정된 미처치 모드에서 유도한 상수**(예 `1.23 × 13.04 = 16.0 ms`, 강건성용 14/18 ms 병기). `u > 0.90` 또는 `u < 0.10`인 셀은 그 추정량을 **mode-pinned**로 라벨하고 헤드라인 인용 금지.
**자기검사**: ✅비용 0·✅절벽이 보이게 됨 · ⚠️**내 처방이 새 자유 표면(`c_valley`)을 만든다** — 유도 규칙과 3값 병기를 함께 등록해야 하며, 그 조건 없이 채택하면 死因이 한 칸 위로 올라간다(P6 전례).

### R3 (필수·둘 중 하나)
- **(a) rung당 시드 ≥2** — 4개 공유 rung에 시드 2개면 main 128 → **192 bench ≈ +2.7 GPU-h**(합계 ≈10.3). ⚠️**비용 중립이 아니다.**
- **(b) 시드 1개 유지 시 §6 검정력 절을 삭제**하고 estimand를 *"등록된 6개 도착 trace 위의 regret"*으로 문자 재정의. 비용 0, 대신 **rung 간 비교(=프론티어)를 주장으로 쓸 수 없다**(실현 log 간격 (0.742, 0.972, 0.158, 0.536)이 시드의 함수).
**자기검사**: ✅(b)는 확실히 실행 가능 · ⚠️(b)는 표제 질문을 **"6개 점"**으로 축소한다.

### R4 (필수·비용 0) — 모양 간 **공통 arm 집합** `𝒜*(λ) := 𝒜(λ,A) ∩ 𝒜(λ,B)` 기준으로 먼저 보고
V3 소멸, A/B 비교 가능. **자기검사**: ✅비용 0 ·✅`μ_p(d92,B)` 실현치와 무관하게 정의됨.

### R5 (필수·비용 0) — erratum 2건 정정 + `μ_p` 출처 단일화

**전체 자기검사**: R1·R2·R4·R5는 전부 비용 0. R3만 비용이 있고 (b)면 GPU 추가 0. ⛔**다섯 개를 전부 이행해도 stake #1은 열리지 않는다.** 어떤 처방도 `GO`를 예약하지 않는다 — **rev5는 재감사 대상이며, 재감사는 V1–V3·§3-(1)(2)(3)을 등록 상수로 승격하지 말고 독립 재검증할 것**(특히 §3-(3)은 이번에 직전 판정서를 부분 정정한 항목).

## 11. 신규 방법론 게이트 후보 (번호 미부여 — doc-steward 소관)

- **(후보 A)** ★★★ **`min`/`argmin` 기반 추정량은 "추정량을 하나로 통일"해도 통일되지 않는다** — `min`이 고르는 **기준 원소가 추정량의 함수**다(실사례: argmin이 `pooled_p95`→d54 12/12, `median`→d16 10/12). 항등식 검사를 결정 규칙 위에서 하라는 기존 교훈의 **기준-원소 판본**.
- **(후보 B)** ★★★ **argmin 산출 금지는 stake 보호 장치이면서 진단 은폐 장치다.** 금지하려면 **"기준 원소가 추정량·셀에 걸쳐 불변인가"라는 불변량 검사는 반드시 산출**해야 한다.
- **(후보 C)** ★★★ **자유 표면을 "동결"한 것을 "제거"라고 쓰지 마라.** 동결은 분산을 편향으로 바꾸고 그 편향은 반복 축에 **완전히 앨리어스**되어 등록 `σ`가 구조적으로 볼 수 없다(실사례: `σ_seed/σ_boot` 3.30×).
- **(후보 D)** ★★ **분포가 이봉이면 백분위·중앙값·절사평균은 각자 다른 절벽을 갖는다.** "네 추정량 동부호" 확인은 **모드 가중 `u`와 함께** 기록되지 않으면 다른 부하로 이식 불가(게이트 #32의 이봉 판본).
- **(후보 E)** ★★ **저장소에 `n_boot>1` 측정이 이미 있는 상수를 `n_boot=1` 값으로 등록하지 마라.**
- **(후보 F)** ★ **등록 상한을 명목 노브에 걸면 실현 축에서는 상한이 아니다**(실사례: `0.95/span_factor` = 0.832–1.663).
- **(후보 G)** ★ **사전등록 예보 표는 전수 재계산해서 실어라**(실사례: 6개 중 1개가 다른 `(seed,N)`의 값, −6.45%).
- **(후보 H)** ★ **파생 요약이 정말 파생인지 검사하라** — 주 산출의 함수로 계산해 값이 같은지 확인.
