## 2. ★미측정 실험 등록부

> 각 항목: **규명 대상**(무엇을 가르는가) · **관측 지표**(무엇을 재는가) · **판정 규칙** ·
> **차단/선행조건** · **비용** · **상태**. 비용은 전부 예약 기준.

### A. 차단이 적어 먼저 집을 것

#### A-1. `P0-A` — graph replay가 SM 한정을 전달하는가 (**구멍 C / 가정 E5**)
- **규명 대상**: green-ctx 스트림에서 **캡처된** CUDA graph를 replay할 때 그 커널들이 green
  context의 SM 부분집합에서만 도는가. ★**운영점은 cudagraph-ON인데 이 저장소의 SM 분할 서사는
  전부 eager 층 근거**다 — 전달 안 되면 **decode 측 분할 서사 전체가 재검토 대상**.
- **관측 지표**: `U(leg)` = 관측된 distinct `%smid` **합집합 크기**, 4-leg
  `{eager, graph} × {green, plain}`.
- **판정 규칙**: `U(graph_green) ≈ U(eager_green)` ∧ `U(graph_green) ≪ U(graph_plain)` ⇒ **전달됨** /
  `U(graph_green) ≈ U(graph_plain) ≈ 108` ⇒ **전달 안 됨(정본 재검토 트리거)** /
  `U(graph_plain)` 미포화 ⇒ `UNDETERMINED (MEASUREMENT ABSENT)`.
- **차단**: ★**설계가 규칙층 미감사**이고 `results/bcg_probe/`에 **사전등록 문서가 없다**.
  미등록 자유 모수 `TOL=4`, docstring이 *"distinct **physical** SMs"* 라 적어 §3.4 상한 위반.
  **선행조건은 충족됨**(R0 = `GLOBALLY_CONSISTENT_LABEL`).
- **비용**: ≈**0.17 GPU-hr**. 하네스는 이미 있고 자기검사 16/16 + 변이 7/7 통과.
- **상태**: ★**이 등록부에서 가장 값싸고 가장 파장이 큰 항목.**

#### A-2. `S-6` — telemetry 계측 오버헤드의 공통 시프트
- **규명 대상**: 계측(telemetry) 유무가 만드는 **공통 시프트의 크기**. 긴장 A의 confound 카탈로그에
  빠져 있던 축 하나.
- **관측 지표**: `d_i = ln M_ttft(OFF_i) − ln M_ttft(ON_i)`(쌍별 로그비), `D_telem = mean_i d_i`.
  판정 셀 = **HI `M_ttft` 단독**(나머지 3셀은 CI만 보고, 판정선 없음).
- **판정 규칙**: **정밀도** — 반폭 ≤ δ. δ = **격자-고유 로그척도 8.68%**(원척도 9.07% 아님).
  최종 구간 = **Stein 2단** `X̄_N ± t_{.975,n₁−1}·S₁/√N`(★`S₁`을 쓴다).
- **차단**: 감사 **C1–C4** — δ 단위 정정 · 작동특성을 **등록 규칙의 것**으로 교체(0.955 → **0.705**,
  ★`n₁=8`이 `n₁=6`을 지배) · `telem_na` **자기증명 라벨** 수리 · "전수" 목록 완성.
- **비용**: 1단 6–8쌍 **1.6–2.1** → 캡 12쌍 **3.25 GPU-hr**(job 2개).
- **상태**: **`GO-with-conditions`**. 차단 4건 전부 GPU 0 문면 작업.

### B. 설계가 아직 통과 못 한 것

#### B-1. `kernel_mech rev7` — decode 스텝 시간의 3분할
- **규명 대상**: 고-SM에서 사라지지 않는 시간이 **커널 실행 / 커널 사이 device 유휴 / 스텝 사이
  호스트 지연** 중 어디에 쌓이는가. ★**"커널 안"이면 P1 판정(ncu×green-ctx 불가)에 의해 이 기판에서
  트랙이 닫힌다** — 종결 조건을 가진 유일한 실험.
- **관측 지표**(1차, 반사실 불요): `gap_frac_intra(D)` · `frac_inter(D)` · `K(D)` · `T_step(D)` ·
  `ε_T(D₁→D₂)`, D ∈ {16, 44, 92}. (2차: 반사실 쌍 `s_A`/`s_B` — ★사전 계산상 가장 그럴듯한 세계에서
  **P≈1.00으로 기권**하므로 정본에 아무것도 더하지 않는다.)
- **판정 규칙**: 1차는 CI 병기 서술. 2차는 두 반사실이 **일치할 때만** `KERNEL_DOMINATED`/
  `GAP_DOMINATED`, 갈리면 **`COUNTERFACTUAL_SENSITIVE`(사전등록된 결과)**, 호스트가 지배하면
  `HOST_DOMINATED(후보 집합 밖)`.
- **차단**: 감사 **B1–B7** — 분모 불일치(`HOST_DOMINATED`가 호스트 지배를 **체계적으로 과소 선언**) ·
  `U_infl` 대수가 CF-A 전용 · 자유 모수 "전수" 오류 재발 · 작동특성이 **축소 규칙·1단 부트스트랩**을
  쟀고 **1차는 작동특성 0건** · "스텝 경계" 미정의 + `A3` 항등식 · ★**B6 적격 창 실현 가능성**
  (`out=128`+`CONC=16`이면 `P(20 step prefill-free) ≈ 0.07`, `--disable-radix-cache` 미고정이
  자릿수로 뒤집음) · 프로브 정의가 **재사용 금지 선언한 rev5에만** 존재.
- **선행조건**: ★**NVTX 엔진 패치**(`grep -rn nvtx src/` → **0건**) = manifest + correctness gate.
- **비용**: 예약 ≈**1.0–1.4 GPU-hr** + 엔진 패치 공수.
- **상태**: `NO-GO`. ★단 감사 원문 *"rev3–rev5의 구조적 死因은 없다 · 핵심 아이디어를 깨지 못한 첫
  판본 · 4연속 NO-GO로 트랙 종결로 읽지 말 것"*. **B6가 예산 승인의 선행 조건**(안 닫히면 D=92 셀
  폐기 → 1차 비교쌍 소멸 → 전액 손실).

#### B-2. `P0-B` — BCG 백포트 스모크
- **규명 대상**: Breakable CUDA Graph를 이 트리(v0.5.10)에 백포트했을 때 (i) 배선되는가
  (ii) `wait_stream` 후킹이 충돌하는가 (iii) **per-break 비용**이 얼마인가.
- **관측 지표**: 부팅 성공 여부 · `wrapped>0`(배선 양성대조) · illegal-memory/capture-fail/hang ·
  **`Median ITL`과 `P99 ITL` 둘 다**(★median으로 재고 p95를 논하는 estimand 바꿔치기 금지).
- **판정 규칙**: `wrapped=0` ⇒ `UNAVAILABLE (BCG PATH NOT WIRED)` · S1 사망 조건 =
  `mean_b delta_6 − 1.96·sd_b/√3 > 0.03·mean ITL(null)`(**신뢰하한** 기준) ·
  변이 검사 `delta_3/delta_6 ≥ 1.5`(미달이면 per-break 비용이 아니다).
- **차단**: 백포트가 **3층**(모듈 4파일 + 서버 플래그 + 캡처 라우팅), **L1 비교가능성 손실**
  (저장소 97개 `.sbatch` 캠페인의 basis), 규칙층 미감사.
- **비용**: **2.5 GPU-hr 예약**(15 부팅).
- **상태**: 설계만 존재. ★**A-1이 먼저**(P0-A가 실패하면 BCG의 S1·S3 둘 다 무의미).
